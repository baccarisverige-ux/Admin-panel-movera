# Movera Admin (A1–A3)

React + TypeScript + Vite. Layout shell, URL routing, design tokens, and all 22
admin screens ported from the static Pages spec (`index.html`, `app.js`,
`styles.css`). Typed mocks live in `src/data/catalog.ts`. Buttons stay local UI.

The live GitHub Pages site is still the three static files at repo root until a
later cutover. Do not point Pages at `webapp/`.

```bash
npm install
npm test
npm run dev
```
